# sss-vid

Application Android minimaliste qui affiche https://ssstwitter.com/ dans une WebView et gère les téléchargements via `DownloadManager`.

## Fonctionnalités
- Affichage du site dans une WebView
- JavaScript activé
- Téléchargement des fichiers via Android `DownloadManager`
- Gestion de la permission de stockage pour les anciennes versions d'Android
- Support du bouton retour dans la WebView
